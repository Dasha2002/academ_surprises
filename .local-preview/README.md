# Локальный просмотр страницы «Новый год»

Откройте терминал в VS Code в корне проекта и выполните:

```powershell
php -S 127.0.0.1:8765 -t . .local-preview/router.php
```

Откройте в браузере http://127.0.0.1:8765/

Мобильный просмотр: http://127.0.0.1:8765/mobile?width=390

Оставьте терминал работающим. Для остановки нажмите Ctrl+C. После изменения файлов темы обновите страницу браузера; сборка не требуется.

Это автономный просмотр, а не полная установка WordPress. Он использует настоящий шаблон `templates/page-novyi-god.php`, CSS, JavaScript и фотографии из рабочей папки проекта. Для общих частей и настроек сохранена копия HTML действующего сайта; нужные шрифты находятся в `fonts/`. Логотип временно заменён текстом, оформление меню упрощено: плагины WordPress здесь не запускаются.

Квиз и поп-ап доступны. Отправка заявок заменена локальным тестом и не отправляет письма. Внизу страницы есть панель проверки успешного и ошибочного ответа. Меню каталога, поиск, админка и реальная отправка требуют WordPress.

Папка `.local-preview` предназначена только для компьютера — её не нужно загружать на хостинг.
